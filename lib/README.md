# lib

Seedling's source, in layers that only depend downward.

- `main.dart` — starts Firebase, turns on offline persistence, runs the app.
- `app.dart` — `SeedlingApp`: the theme, and the auth gate deciding between the
  sign-in screen and the day page.
- `firebase_options.dart` — generated by `flutterfire configure`; do not edit.
- `models/` — plain data classes (`Task`, `Tag`). Depend on nothing.
- `logic/` — pure rules: day keys and the rollover/visibility logic. No Flutter,
  no Firebase, so the app's real behaviour is unit-testable.
- `data/` — the Firestore boundary. Firestore types stop here.
- `theme/` — palette, icon list and the notebook `ThemeData`.
- `widgets/` — the presentational pieces a day page is built from.
- `screens/` — whole screens assembled from those pieces.
